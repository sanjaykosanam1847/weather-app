# Weather App

A simple weather lookup app with city search/autocomplete, current conditions, and a 5-day forecast. Built with vanilla HTML, CSS, and JavaScript, using the [Open-Meteo](https://open-meteo.com/) API for geocoding and weather data (no API key required).

## Structure

```
weather-app/
├── index.html      # Markup
├── css/
│   └── style.css   # Styles
└── js/
    └── script.js   # App logic (search, fetch, render)
```

## Usage

Just open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).

## Deploying with GitHub Pages

1. Push this folder to a GitHub repo.
2. Go to Settings → Pages.
3. Set the source branch (e.g. `main`) and root folder.
4. Your app will be live at `https://<username>.github.io/<repo-name>/`.
